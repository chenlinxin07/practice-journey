# Java 基础学习之旅 (practice-journey)

> 本仓库是我学习 **Java基础** 阶段的所有练习代码与笔记存档。  
> 基于黑马程序员《Java入门到起飞》教程，以“看笔记+写代码”为主完成。  
> 此外还包含一个 `data-structure/` 目录，是我在学习 Java 期间同步练习的数据结构代码，作为基础巩固的一部分一并存档。

## 📌 仓库定位

- **主要用途**：记录 **Java SE** 阶段的学习成果（面向对象、集合、多线程、IO、反射等）。  
- **附加内容**：数据结构基础练习（链表、栈、队列、树等）。  
- **状态**：✅ 已完成，不再频繁更新。  
- **进阶仓库**：后续 JavaWeb、SpringBoot、Redis、项目等内容请移步 👉

3. 每个包内都有独立的 `main` 方法，直接运行即可
